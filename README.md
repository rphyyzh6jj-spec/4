# Albion Flip (PWA)

Веб-приложение для iPhone и Android. Показывает выгодные сделки на рынке одного города:
ордер на покупку чуть выше лучшего, ордер на продажу чуть ниже лучшего, с учётом налога,
сборов, бюджета и объёма продаж за 24 часа. В игре ничего не делает.

## Как выложить (GitHub Pages, бесплатно, ~5 минут)

1. Создай аккаунт на github.com и новый публичный репозиторий, например `albion-flip`.
2. Нажми «Add file → Upload files» и загрузи ВСЕ файлы из этой папки (без самого архива).
   Файлы должны лежать в корне репозитория, не во вложенной папке.
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через 1-2 минуты сайт откроется по адресу `https://ТВОЙ_ЛОГИН.github.io/albion-flip/`.

Альтернатива: Cloudflare Pages или Netlify (перетащить папку в окно браузера).

## Установка на телефон

- iPhone: открой адрес в Safari → «Поделиться» → «На экран Домой».
- Android: открой адрес в Chrome → меню ⋮ → «Установить приложение».

## Если нет данных или ошибка запроса

Приложение ходит в API albion-online-data.com и за списком предметов на raw.githubusercontent.com
прямо из браузера. Если браузер блокирует запросы (CORS), напиши разработчику: нужен небольшой прокси.

Обновление списка предметов: кнопка «Обновить список предметов» в фильтрах.
